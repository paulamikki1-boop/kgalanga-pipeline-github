# Kaempferia galanga Chloroplast Genome Analysis Pipeline

Bioinformatic pipeline supporting comparative chloroplast genome analysis of
narrow- and broad-leaf *Kaempferia galanga*, including gap analysis, SSR
(microsatellite) comparison across 8 *Kaempferia* genomes, primer design and
validation, phylogenetic tree construction, and manuscript figure/table
generation.

## Structure

```
src/
├── core/            CDS parsing, RSCU calculation, variant tables, full analysis
├── primer/          Primer design, in-silico PCR, gel/diagnostic validation
├── ssr/             SSR (microsatellite) detection (single genome)
├── ssr_comparison/  8-genome SSR comparison workbook builders
├── tree/            Phylogenetic tree construction
├── results/         Figure/chart generation
├── manuscript_docs/ Manuscript section & report .docx generators (Node.js)
└── cpgavas/         cpGAVAS-based annotation report builder (Node.js)
```

## Requirements

Python 3.10+:

```
pip install -r requirements.txt
```

Node.js (for manuscript `.docx` generation scripts):

```
npm install
```

## Configuration

Scripts read inputs from `KG_INPUT_DIR` (default `data/`) and write outputs and
intermediate files to `KG_OUTPUT_DIR` (default `output/`). Set them before running:

```
export KG_INPUT_DIR=/path/to/genbank_and_misa_files
export KG_OUTPUT_DIR=/path/to/results
python src/core/parse_cp.py
```

(PowerShell: `$env:KG_INPUT_DIR = "C:\path\to\inputs"`.) Both folders are git-ignored.

## Pipeline stages and key files

Each stage reads the previous stage's files from `KG_OUTPUT_DIR`.

| Stage | Scripts | Main inputs | Main outputs |
|---|---|---|---|
| 1. CDS parsing | `core/parse_cp.py`, `core/step1_parse_cds.py` | GeSeq GenBank files (KS, KB) | `cds_data.json` |
| 2. Codon usage and variants | `core/build_rscu.py`, `core/build_variants_xlsx.py`, `core/full_analysis.py` | `rscu_table.json`, `kb_vs_ref_variants_annotated.json` | RSCU and variant workbooks |
| 3. SSR detection and comparison | `ssr/misa_clone.py`, `ssr_comparison/parse_misa*.py`, `build_corrected_reference.py`, `build_ssr_workbook_v3.py`, `build_combined_workbook_v2.py`, `build_rotunda_parviflora_workbook.py` | MISA `.statistics` / `.misa` files | `misa_parsed.json`, `corrected_reference.json`, 8-genome SSR workbook |
| 4. Genome projection | `primer/build3.py` (latest), `build_matrix*.py` | GenBank files | `primer/proj.pkl` |
| 5. Primer design and validation | `primer/design.py`, `design2.py`, `ispcr.py`, `validate*.py`, `diagnostics.py` | `primer/proj.pkl` | primer tables and figures |
| 6. Phylogeny | `tree/build_tree.py` | `primer/proj.pkl` | `tree/` |
| 7. Figures and manuscript | `results/make_charts.py`, `manuscript_docs/*.js`, `cpgavas/build_docx.js` | JSON and PNG files from earlier stages | `.docx` reports |

### Known gaps

- Some intermediate files (for example `rscu_table.json`, `kb_vs_ref_variants_annotated.json`,
  `doc*_data.json`, `manuscript_numbers.json`) were produced interactively and are not
  yet generated by a script in this repo.
- `manuscript_docs/make_doc*.js`, `make_ms.js` and `make_discussion.js` read their
  inputs from, and write to, the current working directory.
- `src/_archive/` holds earlier versions that were superseded (first two SSR workbook
  builders, 7-genome combined workbook).
- Scripts have been syntax-checked but not re-run end to end after the path change,
  because the input data are not in the repository.

## Data availability

Raw sequence data and chloroplast genome assemblies are deposited under
their respective NCBI GenBank accession numbers (see manuscript Data
Availability statement) and are not included in this repository. Scripts
here expect local GenBank/FASTA input files as described in code comments.
